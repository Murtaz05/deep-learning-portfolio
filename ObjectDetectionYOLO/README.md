# Vehicle Detection with YOLOv8

Trains and compares two YOLOv8 variants (nano vs. small) on a custom vehicle-detection dataset, then evaluates which is the better tradeoff between accuracy and inference cost.

## Approach

1. Convert a flat images+labels folder into YOLO's expected `train`/`val` split layout (`train.py` handles the copy + `data.yaml` generation).
2. Train YOLOv8-nano and YOLOv8-small on the same split, 50 epochs each, 640×640 input.
3. Compare mAP, model size, and (where filled in) inference time between the two.

## Results

| Metric | YOLOv8-nano | YOLOv8-small |
|---|---|---|
| Model size | 12.5MB | 45MB |
| Training epochs | 50 | 50 |
| mAP@0.5 | **0.976** | 0.937 |
| mAP@0.5:0.95 | **0.805** | 0.79 |

**Nano outperformed small on this dataset** — likely because the dataset/task is simple enough (single class: `vehicle`) that the larger model's extra capacity doesn't help and may even overfit faster. Nano is also the better choice for lightweight/edge deployment given the near-identical accuracy.

Loss uses YOLO's composite objective: box loss (CIoU) for localization, objectness loss for false positive/negative penalties, and classification loss.

## Dataset

A single-class ("vehicle") object detection dataset in YOLO format (images + per-image `.txt` label files, one row per box: `class x_center y_center width height`, normalized 0-1). Not included in this repo — place your own here:

```
ObjectDetectionYOLO/
  dataset/
    images/
    labels/
```

`train.py` will split this into `yolo_dataset/{images,labels}/{train,val}/` and generate `yolo_dataset/data.yaml` automatically.

## Setup

```bash
pip install -r requirements.txt
python train.py       # builds yolo_dataset/, trains both models, saves to runs/detect/
python test.py         # loads runs/detect/{yolov8n,yolov8s}_train/weights/best.pt, runs .val()
python test_eval.py    # runs inference + saves a visualized prediction for one sample image
```

Pretrained YOLO weights (`yolov8n.pt`, `yolov8s.pt`) are downloaded automatically by `ultralytics` on first run — they aren't committed to this repo.

## Project structure
